# UI/UX audit register

Findings from a six-part UI/UX audit of every surface, recorded the way
[known-issues.md](known-issues.md) and [threat-model.md](threat-model.md) record theirs:
by name, with the measurement that proves them, whether or not they are fixed yet.

Every finding below was **measured in a rendered panel** — Playwright driving the real
`dist/` bundle in Chromium, and for the injected surfaces the unpacked extension loaded
with `--load-extension` — not read off the source. Where a number appears (`0px`,
`1.00:1`, `332px`), it was observed.

**A caveat that shaped the whole audit.** `preview/ui-preview.html` mounts with
`useShadow: false` and `devtoolsMode: true`, so it is _not_ the shipped docked panel: no
shadow root, no resize handle, no dock or close button. Several defects here are
invisible in the preview and only appear in the real configuration — the focus trap
(S-4) is the clearest case. Anything measured only in the preview is marked as such.

Regenerate the screenshots with `npm run ui:shots`.

**Status.** `FIXED` — closed on this branch, with a regression test naming the old
behaviour. `OPEN` — recorded, not yet fixed. Severity is user impact: **P0** broken or
unusable, **P1** significantly hurts the task, **P2** polish.

## Method

Six independent auditors, each scoped to one surface area and told to measure rather than
read, working from `docs/ui-conventions.md` (the token contract), `PRODUCT.md` (users,
principles, durable constraints) and `CONTRIBUTING.md` (tests pin exact source strings).

Two disagreed, which is worth recording: the accessibility pass measured the modal focus
trap working (0 of 140 tab stops escaped) while the shell pass measured focus escaping to
the host page on Tab #28. Both were right about what they tested — the first used the
preview page, which mounts without a shadow root; the second used the shipped
configuration, which does not. The modals pass then confirmed it independently in-page.
S-4 is real, and the disagreement is the reason this file opens with a caveat about the
preview.
